# Documentation instructions

This is a public repository. Do not publish credentials, customer identifiers,
contact/payment data, internal access instructions or raw operational evidence.
Preserve dated findings as historical evidence; distinguish them from current policy.
Keep implementation and release instructions in their owning code repository.
Use descriptive task branches from develop and open PRs into develop.
Only James may merge or enable auto-merge.
Do not add executable workflows or scripts to this docs repository. Its documents
are checked as data by trusted backend tooling on the shared backend queue.
